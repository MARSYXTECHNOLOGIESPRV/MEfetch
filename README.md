## MEfetch
A system info fetch utility for Mars OS written in rust


*please know that this project I made to teach myself rust. Dont expect a perfect or even functional product. To be fair, dont expect anything I make to work lol*

# Installation
clone the repository with
```
git clone https://github.com/MARSYXTECHNOLOGIESPRV/MEfetch
```
then, enter the directory
```
cd MEfetch
```
build with:
```
cargo build
```
and the binary can be ran with
```
./target/debug/mefetch'
```
or
```
cargo run
```
